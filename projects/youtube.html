About the Project

Decoding the Micro-Creator Playbook

Micro-creators often achieve engagement rates that dwarf larger channels. This project collected data from 1,200+ videos via the YouTube Data API and engineered 15+ features including title sentiment, upload timing, and topic clustering.

Using regression and classification models, I identified top predictors of engagement spikes and built an interactive dashboard for creators to benchmark their content.

Key finding: upload timing and title emotional valence together explained over 40% of variance in above-average engagement rates.
