About the Project

Predicting Risk from the News

Financial markets react to news faster than any human can read — this project automates that signal extraction. Using NLP techniques on 10,000+ financial headlines, I built a pipeline that scores sentiment and detects risk-relevant events in real time.

The model correlates news signals with equity volatility, providing a forward-looking risk indicator that outperforms simple sentiment baselines on held-out test data.

Completed remotely while based in London, working with financial datasets from U.S. and global markets.
