What I built

Most trend tools show you what's already viral — PopFlow was built to catch what's about to peak. The platform aggregates signals from multiple data sources — social media APIs, news feeds, and search trend data — into a unified MongoDB pipeline. The system normalizes and scores trends across domains in near real time, using weighted scoring logic to surface emerging topics before mainstream attention arrives.
